# Шрифты

Balsamiq Sans, Nunito и Rubik — с Google Fonts, лицензия SIL OFL 1.1, без зарезервированных названий.

В латинские наборы (`*-latin.woff2`) добавлен знак U+2011 (неразрывный дефис) — копия обычного дефиса
того же шрифта: типограф сайта (`site/scripts/fix-nbsp.mjs`) ставит его в коротких словах вроде «из‑за»,
а в исходных наборах Google такого знака нет и браузер брал его из системного шрифта.
