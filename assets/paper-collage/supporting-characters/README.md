# Второстепенные персонажи

После проверки фактуры появились [исправленные варианты](../style-revision-2026-10-19/README.md): убраны лишние рябь и тиснение на одежде. Эти исходные версии сохранены для сравнения.

Четыре новых героя в выбранном стиле бумажного коллажа. Каждый — отдельный PNG 1254 × 1254 с четырьмя полными фигурами, сетка 2 × 2. Порядок поз: верхний ряд слева направо, затем нижний.

- [Школьник в очках](classmate-boy-04.png): стоит; машет рукой; идёт с ланч-боксом; держит поднос. Кудрявые тёмные волосы, круглые терракотовые очки, бирюзовая футболка и оранжевые шорты.
- [Школьница с косичками](classmate-girl-04.png): стоит; показывает в сторону; идёт с книгой; держит грушу. Рыжие косички, сиреневая футболка, тёмно-бирюзовый комбинезон с шортами.
- [Повар школьной столовой](canteen-cook-04.png): стоит; держит половник; предлагает миску супа; машет рукой. Зелёная рубашка, кремовый фартук с терракотовым карманом и поварская шапочка.
- [Папа / взрослый для домашних сцен](home-adult-dad-04.png): стоит; идёт с пакетом продуктов; держит тарелку блинчиков; беседует с открытой ладонью. Короткие каштановые волосы и борода, коралловая рубашка, синие брюки.

Сгенерировано встроенным image_gen 19 октября 2026 года. Запросы и референсы сохранены в [prompts.json](prompts.json). Основные герои и прежние материалы сохранены.

Настоящий альфа-канал проверен у всех четырёх листов. Есть слабопрозрачный шум по краям, как у прежних генераций: перед нарезкой нужна очистка альфы. Листы пока не нарезаны и к мультфильму не подключены. PNG не содержит отдельных суставов и слоёв для перекладки.

Размер фигуры на листе не задаёт рост в общей сцене: при монтаже взрослых следует масштабировать выше детей. Новые персонажи — дополнительные варианты для просмотра, без закреплённых имён и сюжетных ролей.
