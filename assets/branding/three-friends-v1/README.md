# 3 друга на тарелке — векторные варианты

Откройте `index.html` для сравнения, `preview.png` — общий лист.

- `title.svg` — заголовок для первого экрана, 970 × 420, прозрачный фон.
- `logo-01.svg` — тарелка; `logo-02.svg` — три продукта-друга; `logo-03.svg` — эмблема с цифрой 3. Все 740 × 250.
- `mark-01.svg`…`mark-03.svg` — отдельные знаки, 256 × 256.
- `favicon-01.svg`…`favicon-03.svg` — специально упрощённые значки, 64 × 64.
- Для каждого favicon есть ICO (16/32/48), PNG (16/32/48/180/192/512); 180 — для apple-touch-icon.
- `title.png`, `logo-*.png` — прозрачные PNG в двойном разрешении.

Это ручные векторные интерпретации присланного экрана, а не автоматическая трассировка. SVG состоят из контуров; в них нет растровых вложений, внешних шрифтов, скриптов или ссылок на другие файлы. Основа букв — Rubik ExtraBold из `shared/fonts`, лицензия SIL OFL 1.1. Небольшие повороты букв и плоские наложенные формы поддерживают стиль бумажных вырезок; шум и имитация тиснения не добавлены.

Предварительная рекомендация: 01 ближе к присланной шапке; 02 лучше передаёт идею трёх друзей; 03 лучше сохраняет узнаваемость в маленьком размере. Варианты не подключены к сайту.

`generate.py` — воспроизводимый исходник SVG; требует Python с fonttools и brotli. Запуск из любого каталога. Растровые превью собраны sharp, ICO — Pillow.
